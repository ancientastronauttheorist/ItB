# Achievement-era archive

Working documents from the achievement-bot phase (April–July 2026, all 70
achievements earned by 2026-07-09), moved here when the project turned to the
perfect-turn engine. They describe the old bot as it was: Rust solver, Codex
and Claude agent rules, goals, logs and checklists. They are history, not
current instructions. See the top-level `README.md` and `CLAUDE.md` for those.

- `README_achievement_bot.md`: the old top-level README, including the
  Lightning War retrospective and the per-achievement unlock notes.
- `AGENTS.md`: the Codex agent guide (the detailed manuals it points to are
  still in `docs/agent/`).
- `LOG.md`, `STATE.md`, `NEXT.md`, `GOAL.md`, `BLOCKERS.md`, `TODO.md`,
  `findings.md`, `EVAL.md`, `HEURISTICS.md`, `STRATEGY.md`,
  `feedback_grid_buy_priority.md`: run logs, goal/state handoffs, the
  achievement checklist and strategy notes.

The decompile research Codex did (July–October 2026) lives on the
`archive/codex-decompile` branch.
